# SortLab · 공개 도메인 명화 이미지

이 디렉터리의 WebP 이미지는 저작권 보호 기간이 만료된 명화의 복제 이미지 또는 NASA 공용 저작물입니다. 각각의 **원본 파일 페이지**를 통해 라이선스 상태를 재확인하고, `scripts/prepare_artworks.py`로 원본의 종횡비를 유지해 960px 이하 WebP로 변환했습니다.

- **큰 파도** — 가쓰시카 호쿠사이 · [원본 파일](https://commons.wikimedia.org/wiki/File:The_Great_Wave_off_Kanagawa.jpg) · Public Domain Mark 1.0 · `greatwave.webp`
- **별이 빛나는 밤** — 빈센트 반 고흐 · [원본 파일](https://commons.wikimedia.org/wiki/File:Van_Gogh_-_Starry_Night_-_Google_Art_Project.jpg) · Public Domain Mark 1.0 · `starrynight.webp`
- **모나리자** — 레오나르도 다 빈치 · [원본 파일](https://commons.wikimedia.org/wiki/File:Mona_Lisa.jpg) · Public Domain Mark 1.0 · `monalisa.webp`
- **그랑드자트섬** — 조르주 쇠라 · [원본 파일](https://commons.wikimedia.org/wiki/File:A_Sunday_on_La_Grande_Jatte,_Georges_Seurat,_1884.jpg) · Public Domain Mark 1.0 · `grandejatte.webp`
- **아이리스** — 빈센트 반 고흐 · [원본 파일](https://commons.wikimedia.org/wiki/File:Vincent_van_Gogh_-_Irises_(1889).jpg) · Public Domain Mark 1.0 · `irises.webp`
- **수련** — 클로드 모네 · [원본 파일](https://commons.wikimedia.org/wiki/File:Claude_Monet_-_Water_Lilies_-_1933.1157_-_Art_Institute_of_Chicago.jpg) · Public Domain Mark 1.0 · `waterlilies.webp`
- **블루 마블** — NASA · 아폴로 17 · [원본 파일](https://commons.wikimedia.org/wiki/File:The_Earth_seen_from_Apollo_17.jpg) · US Government Public Domain · `bluemarble.webp`

작품 이미지를 프로젝트에 포함해 외부 사이트의 런타임 속도·CORS 정책에 의존하지 않습니다. 원본 파일 변경 또는 라이선스 정책 변경이 있으면 재검토해야 합니다.
