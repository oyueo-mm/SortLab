# SortLab

**정렬을 보고, 듣고, 비교하는 인터랙티브 정렬 알고리즘 실험실.**

[웹사이트](https://oyueo-mm.github.io/SortLab/) · [소스 코드](https://github.com/oyueo-mm/SortLab)

## 기능

- 실제 정렬 도감 40종과 패러디·실험 정렬 9종을 분리해 제공
- 카드형 정렬 도감: 한국어 이름 기본 표시, 일반 도감 40종·실험실 9종의 서로 분리된 카드형 미리보기, 기본 초당 24연산, 속도 0.25/0.5/1/2배, 2초 완료 홀드, 보이는 카드만 실행
- 카드 클릭 시 상세 팝업에서 재생·일시정지·단계 이동·재시작·배열 재생성. 본 시각화로 이동은 일반 정렬만 제공
- Web Audio API 기반 높낮이가 다른 음과 완료 스윕 사운드
- 독립적인 4분할 정렬 비교, 동일 데이터에서 동시 재생
- 속도 1~200, 배열 크기 5~1000, 무작위·역순·거의 정렬됨·중복 등 7가지 패턴
- 버블·선택·삽입·퀵·병합·힙 외에 하이브리드·분포·특수·패러디 알고리즘 지원
- 추가 구현: 양방향 선택·빙고·원형·홀짝 병합·패이션스·토너먼트·3방향 퀵·이진 퀵·블록 삽입 병합 등의 정렬
- 패러디 9종: 스탈린·타노스·사회주의·자본주의·수면·보조·기적·양자 보고·슬로 정렬 (알고리즘별 실제 정렬/값 손실/연출 표시)
- 되감기·한 단계 진행·초기화·배열 재생성
- 막대·점·원형 렌더링, 60fps Canvas 2D, 미니멀한 반응형 UI 및 집중 모드
- 의존성 없는 네이티브 ES 모듈, 설치 없이 GitHub Pages에서 실행

## 패러디 안내

**정렬은 원소의 순서를 바꾸면서 원래 원소를 모두 보존해야 합니다.** 스탈린 정렬·타노스 정렬은 값을 삭제하고, SortLab 자체 패러디인 사회주의 정렬은 모든 값을 평균값으로 바꾸므로 정상 정렬이 아닙니다. 자본주의 정렬은 최댓값을 반복 선택하는 SortLab 자체 패러디로 결과가 올바른 순열 정렬입니다. 수면·양자 보고 정렬은 실제 동시 실행이나 양자 연산이 아닌 시뮬레이션입니다. 기적 정렬은 바뀌지 않는 배열을 반복 관찰하다 미완료로 종료할 수 있습니다. 보조·슬로 정렬은 정렬 결과는 보존하지만 극도로 비효율적이므로 입력 크기를 제한합니다.

패러디·실험 9종은 일반 도감에서 검색하거나 선택할 수 없으며, 별도의 사이드바 메뉴에서만 탐색합니다. 일반 시각화·비교 선택창에서도 제외해 혼동을 방지합니다. 보조 정렬과 슬로 정렬처럼 실제로 원본을 보존하며 정렬하는 알고리즘도 실험적 특성 때문에 이 영역에 따로 배치했으며, 상세 팝업에서는 이러한 차이를 설명합니다.

## 실행

Node.js 22 이상 기준:

```bash
npm run dev
```

브라우저에서 http://localhost:4173 에 접속합니다. 의존성 설치는 필요하지 않습니다.

```bash
npm test
```

## 설계

`src/algorithms.js`는 알고리즘 구현과 단계별 이벤트 생성, `src/engine.js`는 재생과 되감기, `src/visual.js`는 Canvas 2D, `src/audio.js`는 Web Audio 합성을 담당합니다. 정렬 비교에서는 배열 생성 시 원본 데이터가 모든 알고리즘에 동일하게 전달됩니다. 이벤트 기록은 메모리를 보호하기 위해 최근 150,000건까지 유지합니다.

특수 정렬은 입력 크기를 제한합니다. 보고 정렬은 최대 5개, 스투지 정렬은 최대 64개, 비드 정렬은 최대 80개까지 지원합니다. 비토닉 정렬은 배열 길이를 2의 거듭제곱으로 맞춥니다.

## 배포

`main` 브랜치 푸시 시 테스트 후 GitHub Actions가 정적 파일을 Pages에 배포합니다. 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택해야 합니다. 안정 버전은 GitHub 릴리스 태그로 별도 보존하는 것을 권장합니다.

## 키보드 단축키

- `Space`: 재생/일시정지
- `←` / `→`: 한 단계 이전/다음
- `F`: 집중 모드
- `Esc`: 팝업/집중 모드 닫기
