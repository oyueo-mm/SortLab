# SortLab

**정렬을 보고, 듣고, 비교하는 인터랙티브 정렬 알고리즘 실험실.**

[웹사이트](https://oyueo-mm.github.io/SortLab/) · [소스 코드](https://github.com/oyueo-mm/SortLab)

## 기능

- 실제 정렬 과정을 표시하는 30개 정렬 알고리즘
- Web Audio API 기반 높낮이가 다른 음과 완료 스윕 사운드
- 독립적인 4분할 정렬 비교, 동일 데이터에서 동시 재생
- 속도 1~200, 배열 크기 5~1000, 무작위·역순·거의 정렬됨·중복 등 7가지 패턴
- 버블·선택·삽입·퀵·병합·힙 외에 하이브리드·분포·특수 알고리즘 지원
- 되감기·한 단계 진행·초기화·배열 재생성
- 막대·점·원형 렌더링, 60fps Canvas 2D, 미니멀한 반응형 UI 및 집중 모드
- 의존성 없는 네이티브 ES 모듈, 설치 없이 GitHub Pages에서 실행

## 실행

Node.js 22 이상 기준:

```bash
npm run dev
```

브라우저에서 http://localhost:4173 에 접속합니다. 의존성 설치는 필요하지 않습니다.

```bash
npm test
```

## 설계

`src/algorithms.js`는 알고리즘 구현과 단계별 이벤트 생성, `src/engine.js`는 재생과 되감기, `src/visual.js`는 Canvas 2D, `src/audio.js`는 Web Audio 합성을 담당합니다. 정렬 비교에서는 배열 생성 시 원본 데이터가 모든 알고리즘에 동일하게 전달됩니다. 이벤트 기록은 메모리를 보호하기 위해 최근 150,000건까지 유지합니다.

특수 정렬은 입력 크기를 제한합니다. 보고 정렬은 최대 5개, 스투지 정렬은 최대 64개, 비드 정렬은 최대 80개까지 지원합니다. 비토닉 정렬은 배열 길이를 2의 거듭제곱으로 맞춥니다.

## 배포

`main` 브랜치 푸시 시 테스트 후 GitHub Actions가 정적 파일을 Pages에 배포합니다. 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택해야 합니다. 안정 버전은 GitHub 릴리스 태그로 별도 보존하는 것을 권장합니다.

## 키보드 단축키

- `Space`: 재생/일시정지
- `←` / `→`: 한 단계 이전/다음
- `F`: 집중 모드
- `Esc`: 팝업/집중 모드 닫기
